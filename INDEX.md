## 🏃 Quick Commands

### Başlatma:
```powershell
# Wizard ile:
.\start-migration.ps1

# Tam otomatik:
.\start-all.ps1

# Batch file:
start-migration.cmd

# VS Code:
F5 → "Web UI + Engine"
```

### Build:
```bash
# Tüm solution'ı build et:
dotnet build OracleMssqlMigration.sln -c Release

# Veya her proje ayrı (MSBuild issue):
dotnet build MigrationShared/MigrationShared.csproj -maxcpucount:1
dotnet build MigrationEngine/MigrationEngine.csproj -maxcpucount:1
dotnet build Migratorv0/Migratorv0.csproj -maxcpucount:1
```

### Manuel Run:
```bash
# Terminal 1:
cd Migratorv0
dotnet run

# Terminal 2:
cd MigrationEngine
dotnet run
```
